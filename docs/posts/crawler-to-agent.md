# 从爬虫到 AI Agent 开发者的转型路线图

我的职业路径：数据科学与大数据技术毕业 → 工业节能行业做软件项目经理（Matlab/PID 控制）→ 自学 Python 转型 → 抖音爬虫 → AI 视频拆解 → AI Agent 应用开发工程师。

很多人在"爬虫"和"AI Agent"之间找不到桥。这篇讲我自己走过的桥，以及每一步**沉淀了什么能力**。

## 阶段一：爬虫——数据获取能力

起步是从抖音数据监控工具开始的：Playwright 驱动浏览器抓取视频信息，FastAPI 做接口，SQLite 存数据，38 个单测。

这个阶段沉淀的能力不是"会爬"，而是：

- **对抗不稳定**：页面结构说变就变，选择器要能容错
- **工程化**：日志、幂等、定时任务、异常告警——爬虫跑一晚上，早上起来要知道它活着
- **数据建模**：27 个字段的数据字典，每条数据有明确来源

爬虫是数据飞轮的第一环：**没有数据获取，后面所有 AI 分析都是无源之水。**

## 阶段二：数据 + AI 分析——从"拿到"到"看懂"

有了数据，下一步是让 AI 看懂。我做了一套视频拆解系统：抽帧 → OCR 字幕 → 情绪/动作/音频分析 → 十岗位拆解。

这个阶段沉淀的能力：

- **多模态管线**：视频是文本 + 图像 + 音频 + 时序的复合体，一条管线把它们串起来
- **本地模型部署**：Ollama 跑 `qwen3-vl:8b` + `qwen2.5:14b`，双服务器分工（4070 采源拆解、A10 生成）
- **防幻觉**：观察与推断分离、全量时间戳、证据可追溯——AI 分析的每个结论都要能指回原视频的时间点

这是最关键的一步：**从"我有一堆数据"到"数据能自动变成洞察"。**

## 阶段三：Agent——从"分析"到"干活"

分析是输出报告，Agent 是闭环干活。推广申请处理 Agent 是转折点：

- 在飞书群里值班，@ 它就处理
- 提取 → 发确认卡片 → 写表格，全程无人值守
- 幂等防重、状态机、26 个单测、准确率 100%

这个阶段沉淀的能力：

- **工具调用**：Agent 要学会用外部工具（读写表格、发消息）
- **状态管理**：pending / confirmed / rejected 状态机
- **可靠性**：重试、退避、故障恢复（这是 Agent 和"玩具"的分水岭）

## 转型的四块垫脚石

回头看，转型能走通靠四件事：

1. **一个真实的项目**，不是课程作业——抖音爬虫 → 拆解系统 → Agent，一路都是真实需求驱动
2. **数据飞轮思维**：采集 → 分析 → 创作 → 回流反哺，系统自我增强
3. **工程洁癖**：测试、文档、幂等、CI——单人开发也要有交付标准
4. **成本意识**：本地优先、免费档默认、按量付费——让项目可持续

## 给想转型的人

如果你现在在爬虫阶段，别急着"学 Agent"，先做两件事：

1. 把爬到的数据**用 AI 分析出结论**（哪怕是一篇拆解报告）
2. 把分析能力**变成自动化的服务**（定时跑、出报告、发通知）

爬虫 → 分析 → Agent，是一个能力连续递进的过程。每一步的产出都是下一步的输入——这就是数据飞轮。走通一次，你就既不是"爬虫工程师"，也不是"只会调 API 的人"，而是**会用数据驱动系统的人**。

这条路我用了一年半走完。你走完需要多久，取决于你第一个真实项目什么时候动手。
