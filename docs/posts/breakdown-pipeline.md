# 五层拆解 + 两层成稿：把爆款视频变成可复用的创作资产

帧间的核心不是"生成一个视频"，而是**把爆款视频拆成可复用的元素，再带进新创作**。拆解和成稿是两条独立管线，各有分工。

## 拆解：五层递进

拆解管线按信息粒度分层推进，每一层只负责一件事：

1. **L1 外围建档**：视频标题、标签、时长、封面、互动数据——先把"外壳"建起来
2. **L2 宏观扫描**：整体结构、节奏、情绪曲线——看骨架
3. **L3 结构拆解**：逐段拆开，转场、钩子、口播结构——看段落
4. **L4.5 内容精拆**：台词逐句、镜头逐帧、BGM 卡点——看细节
5. **L5 元素提炼**：沉淀成可复用的爆款元素（钩子句式、结构模板、情绪节奏）

拆解用的多模态信息源：Whisper 转写台词、按 0.5~1 秒间隔抽帧做视觉理解、完播率等互动数据做筛选门槛。关键帧抽得够密，才撑得起"逐镜头拆解"。

## 成稿：两层 + 确定性后处理

成稿管线刻意**只用两次 LLM 调用**（省成本、控时延）：

```
L1 一次调用 → 整体框架（结构化 JSON）
   ↓
Harness 确定性后处理（时间对齐、格式校验）
   ↓
L2 一次调用 → 完整成稿（Markdown 编导脚本）
```

关键在中间的 **Harness**：LLM 输出时间锚点、格式这类东西会漂，用确定性代码对齐、校验，而不是再丢给 LLM 修——能写代码解决的，不用第二次调用。

## 元素库：拆解和创作的连接器

拆解产出进**元素库**（跨片检索、质控），创作台成稿时按需提取带入。这样每拆一个视频，资产池就厚一点；创作不是从零开始，而是"站在爆款肩膀上"。

## 交付物为什么是"视频说明书"

对编导来说，最有价值的不只是成片，而是**为什么这样做、每一步怎么拍怎么剪**。所以帧间交付的是包含拍摄建议、剪辑建议、节奏设计的"视频说明书"——它让非专业用户也能执行，也让爆款方法论可复制。

> 面试可展开：为什么拆解要分层而不是一次问完？——单次调用信息密度有限，分层让每层 prompt 职责单一、可单独调优、可缓存复用。
