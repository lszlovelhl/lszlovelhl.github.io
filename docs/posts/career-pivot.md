# 从 Matlab 到 AI Agent：我的转行技术路线复盘

我大学读的是数据科学与大数据技术（Python 为主），毕业后第一份工作却做了三年 Matlab——工业智能化软件项目经理，写 PID / GPC 控制算法。离职后转向 Python + AI，做了帧间和两个工程化项目。这条路值得复盘一遍，也许对同样在转型的人有参考。

## 第一站：大学，Python 打底

专业课程以 Python 为主：数据分析、爬虫、机器学习入门。这三年给我的是**数据思维**——处理数据、清洗数据、从数据里找规律。毕业时我以为会去做数据分析，结果去了工业。

## 第二站：三年 Matlab，工业智能化

江苏庞景节能，工业智能化软件项目经理（2022.08 - 2025.10）。

- 用 Matlab / Simulink 开发定制化工业程序与生产数据模型
- PID / GPC 控制算法、OPC UA / DA 协议对接现场数据
- 联合中科大、南京工大做实验室技术到工业应用的转化

这三年教会我三件学校教不会的事：**对接真实系统的脏数据、跟现场打交道、把算法变成能上线的东西**。但我也清楚地看到：工业项目周期长、技术栈封闭，我想要的 AI 应用开发不在这里。

## 转折：离职后系统性补课

离职不是裸奔，是有计划的补课：

1. **Python 主线回归**：把大学的知识重拾起来，以 FastAPI 为主线做项目（爬虫、数据库、Web API）
2. **Java 补后端基础**：自学 Spring / SpringMVC / MyBatis（仓库里还留着 SSM 练习），理解企业级后端的长什么样
3. **前端入门**：HTML / CSS / JavaScript，为了能独立做出完整产品（帧间就是全栈）
4. **AI / Agent**：大模型 API 集成、提示词工程、Agent 应用开发——这是主攻方向

## 现在：帧间 + 两个工程化项目

- **帧间**：爆款视频拆解与创作系统，从产品定义到全栈开发一人完成（React + FastAPI + PostgreSQL + DeepSeek + Ollama）
- **douyin_tool / promotion_agent**：面试题工程化——SQLite、并行、upsert、幂等、Docker、CI、评测，全绿测试

## 复盘：转行做对了什么

- **用作品代替空转**：不纠结"学完再投"，边做项目边学，项目本身就是简历
- **旧经验不浪费**：Matlab 的仿真/数据建模思维直接复用到帧间的数据管线设计
- **每步都可讲述**：转行故事里的每一步都有仓库、有文章、有代码作证——面试官看到的不是一个"想转行的人"，而是一个"已经转了的人"

> 面试可展开：为什么从 Matlab 转 Python/AI？——答：工业项目让我学会真实系统怎么工作，但 AI 应用开发的迭代速度和影响力是封闭技术栈给不了的；转行不是抛弃过去，是把数据建模的经验迁移到新的技术栈。
